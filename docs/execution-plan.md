# Day-by-Day Execution Plan (6 Weeks)

## Week 1
Day 1: Finalize MVP scope and non-goals.
Day 2: Define entities and domain glossary.
Day 3: Draft OpenAPI contract.
Day 4: Auth/session model and security decisions.
Day 5: Clean-room/legal guardrails and CI standards.

## Week 2
Day 6: Monorepo bootstrap.
Day 7: Local infra (Postgres/Redis/S3 emulator optional).
Day 8: Migration framework + base schema.
Day 9: Logging/config/health checks.
Day 10: Frontend shell + route scaffolding.

## Week 3
Day 11: Signup/signin/signout APIs.
Day 12: Refresh token + cookie hardening.
Day 13: Organization create/switch APIs.
Day 14: Role model and access checks.
Day 15: Invite create/list/cancel APIs.

## Week 4
Day 16: Bug report schema and list/detail APIs.
Day 17: Upload session API (presigned PUT).
Day 18: Finalize upload API + validations.
Day 19: Frontend report submission UI.
Day 20: Retry/error mapping for uploads.

## Week 5
Day 21: Screenshot capture flow.
Day 22: Metadata capture and transport.
Day 23: Dashboard list/filter/sort.
Day 24: Report detail + share page.
Day 25: Organization settings UI.

## Week 6
Day 26: E2E coverage for critical paths.
Day 27: Security pass (CORS/CSP/CSRF/rate-limit).
Day 28: Performance pass (indexes/pagination/query audit).
Day 29: Staging release + runbooks.
Day 30: Production launch checklist.
