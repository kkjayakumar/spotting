SPOTTING

Connect your capture key to start reporting bugs from any site.

Local dev: http://localhost:3000. On HTTPS sites (e.g. stage.spotting.dev), the extension proxies to your API — keep localhost if the API runs on your machine. Staging/prod: use your HTTPS API URL.

For QA on any site: in Dashboard → Settings → Public Keys, leave Allowed origins empty (allows all domains).

Supported browsers: Chrome, Edge, Brave, Arc, Opera. Safari and Firefox are not supported yet.
